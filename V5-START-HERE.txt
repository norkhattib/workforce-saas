WORKFORCE V5
============

This version focuses on premium visual polish and usability while keeping the existing Supabase structure intact.

Highlights:
- Exact requested language selector behavior:
  Hebrew/Arabic selected = white background + green text.
  English selected = green background + white text.
- Premium Hebrew/Arabic typography preserved with Heebo / Noto Sans Arabic.
- Refined internal app design, motion, panels, cards, tables, modals and mobile navigation.
- Settings business name field is prefilled with the current business name.
- Settings also shows the current saved business name above the editable input.
- No database migration required for this V5 visual update.

Keep your existing js/config.js Supabase project URL and publishable/anon key.
