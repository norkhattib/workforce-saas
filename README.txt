WORKFORCE SaaS — V2
==================

מה כלול:
- Supabase Auth: הרשמה / התחברות / session.
- Multi-Tenant לפי business_id + RLS.
- 3 שפות: עברית / العربية / English.
- RTL אוטומטי לעברית וערבית, LTR לאנגלית.
- טיפוגרפיה: Heebo לעברית, Noto Sans Arabic לערבית, Inter לאנגלית.
- Dashboard אמיתי.
- Employees: חיפוש, הוספה, עריכה, הפעלה/השבתה, מחיקה לפי הרשאה.
- Shifts: חודש, חיפוש, הוספה/עריכה, לקוח, מיקום, שעות, סטטוס.
- Shift Employees: שיוך עובד למשמרת, שעות, שני מחירים, רכב ותוספות.
- Advances: נותן מפרעה דינמי, עובד, תאריך, סכום וסיבה.
- Payroll: ברוטו, שולם, נטו לתשלום וסימון כשולם.
- Settings: שם עסק, שפה, מטבע, סף שעות, עיגול, נותני מפרעות, לקוחות ומיקומים.
- Mobile-first responsive UI.

הגדרה ראשונה:
1. פתח js/config.js.
2. הזן SUPABASE_URL של הפרויקט החדש.
3. הזן Publishable/Anon key בלבד. לעולם לא service_role.
4. ודא שה-SQL של Phase 1, Phase 2 ו-Phase 2.5 כבר הורץ.
5. אם עדיין לא הרצית database-grants.sql, הרץ אותו ב-SQL Editor.
6. העלה את התיקייה ל-Netlify או הרץ דרך שרת סטטי מקומי.

בדיקה מומלצת:
1. register.html -> צור משתמש.
2. onboarding -> צור עסק.
3. Settings -> הוסף נותן מפרעה, לקוח ומיקום.
4. Employees -> הוסף עובד ושני מחירי שעה.
5. Shifts -> צור משמרת ושייך אליה עובד.
6. Advances -> הוסף מפרעה.
7. Payroll -> בדוק ברוטו / שולם / נטו.
8. צור משתמש/עסק נוסף ובדוק שאין חשיפה בין העסקים.

הערה:
הגרסה הזאת היא בסיס מוצר SaaS פעיל. לפני מכירה ללקוחות אמיתיים נוסיף בהמשך הזמנות משתמשים/צוות, מנויים, audit log, איפוס סיסמה, אימות מייל production ועוד.
